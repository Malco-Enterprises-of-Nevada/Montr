# Product Overview

## Media Playlist System

A Node.js application for managing and playing media playlists with two main components:

- **Client Player**: Dedicated application for continuous media playback (videos and images) with automatic playlist progression and real-time updates
- **Web Management Interface**: Browser-based playlist creation, media upload, and playback control system

## Key Features

- Real-time playlist management and control
- Support for video (MP4, AVI, MOV, WebM) and image (JPG, PNG, GIF, WebP) formats
- Automatic continuous playback with looping
- Live playlist switching across connected clients
- Network resilience with offline playlist caching
- Media preview and metadata extraction

## Use Case

Designed for digital signage, kiosks, or display systems where centralized content management is needed with distributed playback clients.
